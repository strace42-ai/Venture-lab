## 2. Шаг A — что показала проверка пилотного файла `pilot-001`
- `research:draft-check`: вердикт «готов к проверке основателем (НЕ одобрен)». Ошибок нет; по каждой из 3 идей одно предупреждение «нет оценки» (это допустимо).
- `research:import` (dry-run): +3 идеи, +17 источников, +13 конкурентов, 0 оценок. Применение **заблокировано шлюзом**: ai-draft и файл из `research/drafts/`.
- Повторно открыты 12.11.2026:
  - **ВНИКЛИ** — сравнение 2–3 КП в PDF/DOCX/XLSX, 990 ₽ за два КП и 1 290 ₽ за три. Сервис «не выбирает победителя».
  - **Vortholm** — «корпоративная ИИ-платформа для сравнения коммерческих предложений»: подписка плюс оплата ИИ по собственному ключу клиента; цена после встречи.
  - **Aether Lab** — гайд и предложение «Универсального ИИ-агента» с тарифами 1 990 и 3 990 ₽/мес.
  - **Cofocus** — групповые созвоны по 90 минут, 1 990 ₽/мес.
  - **StudyMates** — бесплатно 45 минут в день, есть Pro.
  - **Mnesikles** — Telegram-бот; Premium бесплатен до 31.12.2026.
  - **beamai.ru** из этой сессии не открылся: ошибка DNS или сетевое ограничение среды.
- Вывод: для `supplier-quote-compare` гипотеза о незанятой нише **не подтверждается**. Оценку новизны снижаем, а формулировку `ruUnmetJob` в файле («ГИПОТЕЗА НИЗКОЙ НЕЗАНЯТОСТИ…») считаем корректной. Цены ВНИКЛИ и Aether Lab выше — это наблюдения Claude Code. В JSON они не добавлены: источники неизменяемы, и при одобрении их можно внести новым прогоном.

## 4. Предварительное обоснование (без баллов)
Баллы рубрики **не выставлены**: это требование задачи, а ИИ не оценивает свои собственные источники. Качественная прикидка по 12 критериям `docs/scoring-model.md` следующая:
- **Сильнее всего:** `str-guest-guide-ru`. Есть понятный западный продукт, быстрый MVP и дешёвый тест, а прямой РФ-аналог не найден. Слабое место — проверка PMS.
- **Вторая группа:** `virtual-focus-coworking-ru` (оплата в РФ есть, ниша 1-на-1 узкая), `vag-autoscan-report` (дешёвый тест, спрос неизвестен), `appliance-fix-assistant-ru` (сильный западный сигнал, слабая монетизация).
- **Слабые:** `personal-crm-ru`, `solo-client-room` (бесплатные или универсальные субституты).
- **Отклонить:** `pain-radar-ru`, `supplier-quote-compare` (как общий продукт), `sales-gamification-smb`.

Весовая модель скоринга не менялась. В рейтинг (ТОП-10) ничего не попадает, пока нет вашей проверки и оценки.

## 5. Как утвердить (только вы)
1. Откройте источники по `first-real-pilot-source-index.csv` (сначала приоритет `high`) и пройдите чек-лист из раздела 3.
2. Для одобренных идей создайте файл в `research/inbox/` с `"source": "human-reviewed"`, ваш блок `approval {approvedBy, approvedAt, statement}`, `reviewedBy` на проверенных источниках. Отклонённые идеи и утверждения уберите.
3. `npm run research:draft-check -- research/inbox/<файл>.json`, затем `npm run research:import -- research/inbox/<файл>.json` (dry-run) и только после этого `--apply`.
4. Оценки по рубрике добавляются отдельной ревизией после проверки источников.
