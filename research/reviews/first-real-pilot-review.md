# Первый реальный исследовательский пилот — сводка (ревизия 2 после аудита)

**Задача:** VL-003P · **Наблюдения:** 2026-11-12 · **Статус:** черновики ИИ (`ai-draft`), в REAL **не импортированы**, оценок нет.

## Как читать этот пакет (после решения основателя v2.0)
Основатель решил: **ежедневная бизнес-разведка полностью автономна, без обязательного участия человека**
(`docs/no-vpn-automation-architecture.md` v2.0, `tasks/backlog/VL-004A-autonomous-research-worker.md`). Поэтому этот PR — это:
1. **Тест совместимости старого ручного пути импорта** (legacy manual-import: `ai-draft` → `draft-check` → dry-run → шлюз). Шлюз корректно отказывает в применении черновиков.
2. **Корпус источников для будущего автономного воркера VL-004A:** 41 источник, конкуренты, отрицательные результаты поиска и опровергнутые гипотезы. Это готовые тестовые случаи для «скептика» и quality gates.

**Ручная проверка 41 ссылки, ручное одобрение и ручной импорт НЕ являются условием дальнейшей работы**: ни разработки VL-004A, ни будущих ежедневных исследований, ни автоматического рейтинга. Основатель *может* исправить запись по желанию; по v2.0 такая правка становится отдельным версионированным входом для следующих автоматических прогонов.
Статусы `human-reviewed`, `checked` или `approval` нигде не проставлялись и не подделывались.

**Состояния v2.0 для кандидатов этого пакета.** Ни один кандидат не получил `AUTOMATED_EVIDENCE_PASSED`: машинных проверок VL-004A ещё нет. Каждый кандидат либо `DISCOVERED` (найден, не ранжируется), либо предлагается в `RESEARCH_HOLD` (доказательства опровергнуты или недостаточны). Результат — **9 кандидатов, а не 10**; рейтинг не заполняется искусственно.

**Файлы:**
- `research/drafts/draft-2026-11-12-pilot-001.json` — 3 кандидата (ChatGPT; содержимое не менялось);
- `research/drafts/draft-2026-11-12-pilot-002.json` — 6 кандидатов, **ревизия 2**: гид гостя и VAG Report переписаны по аудиту;
- `research/reviews/first-real-pilot-source-index.csv` — 41 источник: статус машинной проверки, статус загрузки, приоритет перепроверки.

> Все утверждения — пересказ страниц инструментом ИИ. Описания вендоров подтверждают **существование предложения**, а не число клиентов или платежей.
> «Не найдено» означает только «не найдено в перечисленных запросах». Если страница не загрузилась **в среде воркера**, это не доказывает, что сервис недоступен пользователям.

## 4. Обоснование без баллов
Баллы по рубрике **не выставлены**: ИИ не оценивает собственные источники, а машинного evidence-pass ещё нет. Весовая модель `docs/scoring-model.md` не менялась, рейтинг не заполняется.
Качественно по рубрике: у всех 9 кандидатов слаб критерий «слабость РФ-конкурентов / незакрытая работа в РФ». У №6–9 он опровергнут. У №3 смежная работа уже бесплатно закрыта VAGLOGS, а спрос на оставшуюся не подтверждён. У №4–5 есть бесплатные или универсальные субституты. У №1–2 доказательств недостаточно.

## 5. 7-дневные тесты — только гипотезы
Тесты, описанные в первой ревизии (лендинги, опрос хозяев, сбор логов), — **гипотезы для возможного будущего эксперимента**, который запускается отдельным заданием. Они не входят в автономную интернет-разведку и не гарантируют валидацию. **Никому не писать без отдельного задания.**

## 6. Старый ручной путь импорта (необязательный, для совместимости)
Если основатель когда-нибудь захочет занести запись в старый ручной REAL-датасет:
1. создать `human-reviewed` файл с собственным `approval` в `research/inbox/`;
2. выполнить `draft-check`, затем dry-run и `--apply`.

Это не требуется для VL-004A и для ежедневных автоматических исследований.
