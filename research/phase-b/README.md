# Phase B — заданные кандидаты испытания

`seeds-stage2.json` (1 кандидат) и `seeds-stage3.json` (4 кандидата) — гипотезы из контрольного корпуса VL-003P (`research/reviews/first-real-pilot-review.md`). Это **не утверждения о рынке**: только название, задачи (jobs), западный аналог с его URL из корпуса и русские ключевые слова для поиска конкурентов. Все факты система устанавливает сама во время испытания.

Сырые ответы провайдеров сюда **не кладутся** — они сохраняются локально вне Git (`~/.venture-lab/phase-b/<trial>/raw`, см. `docs/vl-004b-phase-b-trial-plan.md`). В репозиторий попадают только специально очищенные фикстуры.
