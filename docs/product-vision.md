# Venture Lab — Product vision v1

## North star
A premium-looking, useful **AI Business Command Center** for one founder who researches global software opportunities, verifies gaps in Russia, validates payment demand, develops and launches products with ChatGPT + Claude Code + Codex. The interface should be so clear and beautiful that screenshots communicate its value, without deceptive mock claims.

## Target persona
Phase 1: founder / solo builder using React+TypeScript, Claude Code and ChatGPT. Future (not MVP): indie founders, boutique studios, micro-SaaS operators.

## Core jobs to be done
1. Each morning see NEW researched opportunities, current top ten across all time, movements, evidence freshness and uncertainties.
2. Drill into any opportunity: foreign analogues, Russian competitors, precise unmet use case, economics, technical risks, first-customer plan.
3. Understand **why** a score changed, not just a number; compare scores and confidence.
4. Decide whether to research, test, build, pause, kill; log rationale.
5. For validation: record interviews, offers, deposits, real conversions and costs.
6. For builds: see GitHub repo, PRs, branches, test and review status plus current task/handoff.
7. Later, inspect revenue, API costs, hosting, gross margin and retention for launched products.

## Navigation / information architecture
- **Overview**: opportunity pulse, strongest new find, Top 10 preview, experiment funnel, active builds, activity, alerts; clear mock/demo labels.
- **Radar**: searchable/filterable ideas table/card views (category, market, B2B/B2C, score, confidence, stage, evidence age, risks), saved views.
- **Idea dossier**: thesis, user/job/problem, Western proof, Russia competition matrix, score subcriteria, evidence citations, risks, unit economics, MVP, distribution, first 10 customers, validation plan and score-history.
- **Validation Lab**: experiment hypothesis, channel, offer, outreach, interviews, payment confirmations, spend, decision.
- **Build Studio**: authorized current task, branch, PR, CI, test outcomes, reviewer findings, handoff. Phase 1 UI demonstration only.
- **Portfolio**: projects and lifecycle, spend, revenue and portfolio decisions.
- **Research Journal**: dated research runs, new ideas, accepted/rejected changes, top-10 snapshots, source changes.
- **Settings**: scoring weights/version (future, no hidden weight changes), integrations, currency, cost controls.

## Lifecycle
Discovered → Researching → Scored → Validation planned → Validating → Paid signal → Build candidate → Building → Launched → Monetizing.
Side states: Paused, Rejected, Archived. All transitions should eventually be audited, including reason and actor.

## Key differentiators
- Evidence-backed score, confidence and source provenance separate from opinion.
- Russia-specific competitive gap, not generic global startup directory.
- Founder-fit as additional diagnostic, not secretly mixed with market score.
- Decision log and experiments before coding.
- GitHub-backed AI collaboration / auditable handoffs.
- Longitudinal TOP-10, scores versioned over time, real market changes.

## Truth constraints
A marketing mock may use conspicuously labeled demo data. Never present fake ARR, revenues, live AI agents, live GitHub status, citations or customers as real. All production statements require source and provenance.

## Success signals
Time to first valid evidence, number of experiments with measurable result, days to first paid pilot, rate of repeated use, successful handoff without copy/paste, recurring revenue less direct expenses.
